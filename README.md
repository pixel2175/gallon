# Gallon

A Flask-inspired web application server written in Go with Lua scripting.

## How Gallon Works

Gallon uses Go's `net/http` to handle HTTP requests and Lua to define application logic. Write your web application in Lua, and Gallon executes your scripts to process requests and generate responses.

## Installation


```sh
make build # build the project
```

```sh
make install # build and install
```


```sh
make uninstall # uninstall
```
